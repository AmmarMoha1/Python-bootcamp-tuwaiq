# Day 07 - Python Variables and Data Types

## Overview
This lab covers the fundamentals of Python, including:

- Variable assignment
- Reassigning variables
- Case sensitivity
- Data types
- Constants (naming convention)
- Type checking with `type()` and `isinstance()`
- User input
- Type conversion
- String indexing

## Labs

### Lab 1: Variable Assignment
- Assign variables
- Reassign values
- Understand case-sensitive variable names

### Lab 2: Data Types
- String
- Integer
- Boolean
- Constants using uppercase naming convention

### Lab 3: Type Conversion
- Read user input using `input()`
- Convert strings to integers with `int()`

### Lab 4: String Indexing
- Access characters using indexes
- Validate user input before indexing

## How to Run

```bash
python3 main.py
```

## Learning Objectives

- Understand how variables work in Python
- Learn the basic Python data types
- Practice user input and type conversion
- Work with strings and indexing
