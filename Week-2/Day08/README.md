# Python Basics Labs

This repository contains my Python practice labs covering the fundamentals of Python programming.

## Topics Covered

* Arithmetic operators and calculations
* Floor division and modulus operations
* Operator precedence
* Boolean values and logical operators
* Comparison operators
* Assignment operators
* Lists and list operations
* String indexing and slicing
* String methods:

  * `split()`
  * `join()`
  * `strip()`
  * `lower()`
  * `title()`
  * `replace()`
  * `find()`
* String immutability and handling errors using `try` and `except`
* Difference between `==` and `is`
* User input and type conversion
* Basic problem-solving exercises

## Lab Summary

In these labs, I practiced Python fundamentals by creating small programs to understand how variables, operators, strings, lists, and user inputs work. I also learned how to handle errors and work with Python built-in methods.
