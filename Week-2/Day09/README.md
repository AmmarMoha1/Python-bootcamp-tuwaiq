# Python Conditions Labs

This repository contains a collection of Python labs focused on understanding and practicing conditional statements and decision-making in Python.

## Topics Covered

* `if`, `elif`, and `else` statements
* Comparison operators (`>`, `<`, `>=`, `<=`, `==`)
* Logical operators (`and`, `or`, `not`)
* Nested conditional statements
* Boolean values and truthy/falsy concepts
* Input validation using string methods
* Type conversion (`str` to `int`)
* Checking user input with methods like:

  * `isdigit()`
  * `isalpha()`
  * `replace()`
  * `strip()`
* Membership checking using `in`
* Pattern matching using `match/case`

## Labs Overview

* **Lab 1:** Basic `if` conditions and code execution flow.
* **Lab 2:** Using `if/else` for temperature checks.
* **Lab 3:** Creating a grading system using `elif`.
* **Lab 4:** Applying logical operators and user permissions.
* **Lab 5:** Working with nested conditions.
* **Lab 6:** Understanding truthy and falsy values.
* **Lab 7:** Validating user names with string methods.
* **Lab 8:** Validating numeric input and performing calculations.
* **Lab 9:** Building a score validation system.
* **Lab 10:** Checking membership permissions.
* **Lab 11:** Using `match/case` statements for command handling.

## Goal

The goal of these exercises is to build a strong understanding of Python decision-making, write cleaner conditional logic, and handle different user inputs safely.

## Skills Practiced

* Problem solving
* Conditional logic
* Input validation
* Writing readable Python code
* Handling different program scenarios
