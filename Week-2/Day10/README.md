
# Python Loops Practice

This section contains practice exercises and labs focused on Python loops.

## Topics Covered:

* Using `for` loops to repeat tasks.
* Using `range()` with different start, stop, and step values.
* Looping through strings and lists.
* Checking even and odd numbers using the modulus operator `%`.
* Using counters to count specific values.
* Using accumulators to calculate totals.
* Working with `while` loops for repeated user input.
* Implementing input validation using loops.

## Practice:

* Created a program that takes a maximum number from the user.
* Identified even and odd numbers between 1 and the given number.
* Counted the number of even numbers.
* Calculated the sum of all even numbers.

## Labs:

The labs include different examples of:

* Counting attempts.
* Printing number sequences.
* Creating countdown timers.
* Iterating through collections.
* Calculating totals with VAT.
* Building simple input validation systems.
* Understanding the difference between `for` and `while` loops.

These exercises improved my understanding of loops, conditions, counters, and basic problem-solving in Python.
