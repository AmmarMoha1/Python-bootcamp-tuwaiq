
# Python Functions Labs & Practice

This section covers Python functions and how they are used to organize and reuse code.

## Labs

### Lab 1 – Basic Function

* Created a simple function using `def`.
* Called the function to execute its code.

### Lab 2 – Function Calls

* Created a function to display a menu.
* Practiced calling the same function multiple times.

### Lab 3 – Function Execution Flow

* Practiced how Python executes code before and after a function call.
* Learned that a function runs only when it is called.

### Lab 4 – Function Parameters

* Created a function that accepts a parameter.
* Used the parameter inside the function.

### Lab 5 – Default Parameters

* Practiced using default parameter values.
* Used `isdigit()` to validate the number of nights before converting it to an integer.
* Practiced passing different arguments to a function.

### Lab 6 – Return Values & Function Attributes

* Created a VAT calculation function with a default rate of 15%.
* Practiced returning values using `return`.
* Used different VAT rates by passing arguments.
* Explored function attributes such as `__doc__` and `__name__`.
* Used `help()` to view function documentation.

## Practice – Grade Calculator

Created a grade calculator using a Python function.

The program:

* Takes the student's name and score as input.
* Validates the student's name.
* Checks that the score is a valid number.
* Ensures the score is between 0 and 100.
* Calculates the grade from A to F using `if`, `elif`, and `else`.
* Displays the student's name, score, and final grade.
* Uses `return` to stop the function when invalid input is detected.
