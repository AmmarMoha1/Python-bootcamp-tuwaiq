
# Python Scope & Namespace Practice

This practice covers Python **Scope and Namespace** concepts through several labs and exercises.

## Topics Covered

* Global and Local Scope
* `globals()` and `locals()`
* `nonlocal` keyword
* Variable shadowing
* Function scope and nested functions
* Function parameters and return values
* Function call hierarchy
* Modules and `import`
* `if __name__ == "__main__":`
* Basic grade calculation using functions

## Labs

The labs demonstrate how Python handles variables and functions in different scopes, how namespaces can be inspected, and how nested functions access variables from outer scopes.

## Practice

Created a separate `grades` module containing a grade calculation function, then imported and used it from another Python file.

The practice also demonstrates the purpose of:

```python
if __name__ == "__main__":
```

and how Python modules can be executed or imported.
