# Python Collections Lab

In this lab, I learned and practiced Python **collections** and how to work with different data structures.

### Topics Covered:

- **Lists**: indexing, slicing, updating elements, `append()`, `insert()`, `remove()`, `pop()`, `sort()`, and `sorted()`.
- **Tuples**: accessing elements, unpacking, and understanding that tuples are immutable.
- **Sets**: storing unique values, adding and removing elements, and using set operations such as:
  - Union `|`
  - Intersection `&`
  - Difference `-`

- **Dictionaries**: accessing and updating values, adding and removing keys, using `get()`, `pop()`, and `items()`.
- **Loops**: iterating through lists, dictionaries, sets, and strings using `for`.
- **`enumerate()`**: getting both the index and value while looping.
- **Nested collections**: working with lists containing dictionaries, tuples, and sets.
- **String iteration**: looping through the characters of a string.
- **Built-in functions**: practicing `sum()`, `min()`, `max()`, `len()`, and `sorted()`.
- **Math module**: using `math.sqrt()` and exploring module documentation with `math.__doc__`.

### Practice

I applied these concepts by creating a list of students containing their names, scores, and skills. I calculated each student's average score, added skills using sets, and looped through the data to display the results.
