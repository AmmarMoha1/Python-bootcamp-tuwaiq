## List Comprehensions

In this lab, I practiced Python comprehensions and learned how to create and transform collections in a concise way.

### Topics Covered
- List Comprehension
- Set Comprehension
- Dictionary Comprehension
- Expressions
- Clauses
- Filters using `if`
- Conditional Expressions using `if ... else`
- Using methods such as `strip()`, `title()`, and `lower()`
- Nested `for` clauses
- Removing duplicates using Sets
- Creating dictionaries with key-value expressions

### Practice Examples
- Extracting odd numbers and calculating their squares
- Adding VAT to prices
- Filtering passing scores
- Cleaning and formatting names
- Creating pairs from two lists
- Generating `"pass"` or `"retry"` labels based on scores
- Extracting email domains
- Creating a dictionary of numbers and their squares
