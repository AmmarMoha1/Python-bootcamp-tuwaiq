File Handling & pathlib in Python
Overview

In this practice, I learned how to work with files and file paths in Python using the built-in pathlib module.

The main topics covered were:

Creating and working with Path objects
Building file paths in a portable way
Checking directories and files
Creating directories with mkdir()
Reading files
Writing and replacing file contents
Appending data to existing files
Creating files only when they don't exist
Using with to automatically close files
Iterating over files line by line
Writing multiple lines using join()
Working with UTF-8 encoding
