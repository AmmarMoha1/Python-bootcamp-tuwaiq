# UML Diagrams – Add Student

Today, I learned about three UML diagrams:

* **Use Case Diagram** – shows how the user interacts with the system to add a student.
* **Activity Diagram** – shows the steps and flow of the Add Student process.
* **Class Diagram** – shows the classes, attributes, methods, and relationships related to adding a student.

I practiced these diagrams by designing the **Add Student** feature and representing it using all three UML diagrams.
