HOW THE WEB WORKS

HTTP

How It Works

  1. The client (browser) sends a request to the server.
  2. The server processes the request.
  3. The server sends a response back to the client.
  4. The browser displays HTML, CSS, JavaScript and images.

HTTP – How the Web Works

HTTP stands for HyperText Transfer Protocol. It defines how messages are formatted and transmitted between clients and web servers.

Request Methods

GETRequest data from the server
POSTSend or create data
PUTUpdate data
DELETEDelete data

HTTP Flow

💻
Client Browser
Request →
← Response
🖥️
Server Backend

Status Codes

  • 200 OK — Request succeeded
  • 201 Created — Resource created successfully
  • 400 Bad Request — Invalid request
  • 401 Unauthorized — Authentication required
  • 404 Not Found — Resource not found
  • 500 Server Error — Internal server problem

WHAT IS WEB DEVELOPMENT?

Building Websites & Web Applications

Web development is the process of creating websites and applications that run on the Internet. It includes the structure, styling, behavior and interaction of web pages.

  2. Internal CSS — inside a <style> tag.

BUILD FOR ALL SCREENS

Responsive Design

Responsive Design

Responsive design makes websites work well on phones, tablets, laptops and desktop screens.

📱 💻 🖥️

Key Concepts

  1. Viewport Meta Tag 
    <meta name="viewport"
content="width=device-width,
initial-scale=1.0">
  2. Media Queries 
    @media (max-width: 768px) {
    .container {
        width: 100%;
    }
}
  3. Flexible Units — %, rem, vw, vh.
  4. Breakpoints
    • Mobile: up to 576px
    • Tablet: 577px – 992px
    • Desktop: 993px and above
  5. Flexible Layouts — Flexbox and Grid.

BRING YOUR WEB PAGES TO LIFE

Animation

CSS animations allow elements to gradually change from one style to another.

Transition

Applies changes smoothly over a specified duration.

.button {
    transition: 0.3s ease;
}

.button:hover {
    background: green;
}

Transform

Changes the shape or position of an element.

.box:hover {
    transform:
        scale(1.1)
        rotate(5deg);
}
Hover

Keyframes Animation

Creates more complex animations using keyframes.

@keyframes slide {
    0%   { left: 0; }
    50%  { left: 100px; }
    100% { left: 0; }
}

Common Timing Functions

  • ease — slow start, fast middle, slow end
  • linear — constant speed
  • ease-in — slow start
  • ease-out — slow end
  • ease-in-out — slow start and end
✓ Use subtle animations ✓ Keep durations short ✓ Do not overuse animations ✓ Maintain good performance
